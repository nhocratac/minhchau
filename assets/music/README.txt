ĐẶT FILE NHẠC NỀN VÀO THƯ MỤC NÀY
===================================

1. Chép file nhạc .mp3 của bạn vào đây.
2. Đổi tên file thành:  music.mp3
   (hoặc giữ tên cũ và sửa dòng  music.src  trong assets/js/config.js)

Gợi ý:
- Dung lượng nên dưới 5 MB để khách mở thiệp nhanh (128 kbps là đủ).
- Nhạc sẽ tự lặp lại và bắt đầu phát khi khách chạm vào cánh cửa.
- Nếu chưa có file, nút nhạc sẽ tự ẩn, trang vẫn chạy bình thường.
- Nên dùng nhạc bạn có quyền sử dụng (nhạc miễn phí bản quyền, nhạc tự làm...).
